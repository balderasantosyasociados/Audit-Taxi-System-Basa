## 🚀 CARACTERÍSTICAS BASA V4 FULL

### 🔐 Acceso BASA - Sin mostrar ID personal
- **Master Admin:** Usuario `basa.admin` / Clave `BASA_2026_MASTER` - Control FULL
- **Cliente USA:** Entra solo con **1 dato**: `ID / ITIN / NSS` - Sin registro complicado
- **Cambio de clave:** Después de entrar, cambia clave y se guarda histórico sin vencimiento

### 📜 Contrato Legal Obligatorio
- Firma digital **SHA-256** declarando información **real y verificable**
- Cliente declara bajo juramento ser **responsable legal** de soportes
- Cumple leyes **IRS, NOBACI, ISSAI, INTOSAI, Ley 10-07, 41-08, 126-01, 340-06**

### 📂 Carga de Soportes y Evidencias Ley USA
- **Formatos:** Word (.docx), Excel (.xlsx/.csv), PDF, TXT, Imágenes (.png/.jpg)
- **Evidencias IRS:** W2, 1099, ID, Contratos, Facturas, Conduces
- **Extracción 100% Real:** Sin inventar datos - Extrae de documentos reales
- **Guardado automático:** `evidencias_auditoria/` y `reportes_exportados/`

### 📊 Dashboard Visual BASA
- **Radar 0-10:** Nivel de riesgo por área auditada (10=Óptimo)
- **Barras Presupuesto:** Distribución por área en RD$ / USD $ / EUR €
- **Debajo de Matriz Riesgos:** Integrado con `plotly` (equivalente recharts)

### 📋 Matriz Hallazgos Editable en Pantalla
- Editar título, rubro, monto, condición, score 0-10, página fuente
- **Salvar / Borrar / Base Limpia (0) real** - Borra todo 100%
- **Histórico:** Guardar caso, retomar, editar, borrar - Master ve todo

### 🌍 Internacionalización USA + RD
- **Países:** 🇩🇴 RD - RD$, 🇺🇸 USA - USD $, 🇪🇸 ES - EUR €, 🇲🇽 MX, 🇨🇴 CO, 🇵🇦 PA
- **Normas:** ISSAI 5000 Forense, INTOSAI, NIA/ISA, NIIF, NICSP, NOBACI

### 📤 Exportación BASA
